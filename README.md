# Iskolai affiliate app – interaktív mobilkoncepció

Kattintható iPhone-demó a fő iskolai szervező operatív és affiliate folyamataihoz. A teljes működés frontend-szimuláció, valódi backend és pénzmozgás nélkül.

## Demóútvonal

1. Reális, osztályléptékű jegyeladás és pénzbeszedés követése
2. Promóterek osztályának, teljesítményének és elszámolásának kezelése
3. Saját ajánlói link vagy kód küldése egy másik iskola leendő főszervezőjének
4. Sikeres partneriskolai szerződésenként járó 25 000 Ft jutalék követése
5. CRM-szinkron látványos szimulációja

Az oldal mobilon teljes képernyős, asztali nézetben iPhone-keretben jelenik meg. Érintéses lapozást és nyílbillentyűs navigációt is támogat.

A `main` ágra történő push automatikusan elindítja a GitHub Pages publikálását.
